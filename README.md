# LedgerBank

A secure digital banking platform built using React, Node.js, Express, PostgreSQL, and Prisma.

## Features

- User Authentication
- Account Management
- Beneficiary Management
- Money Transfers
- Double Entry Ledger System
- Admin Dashboard

## Tech Stack

### Frontend
- React
- Tailwind CSS
- ShadCN UI

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL
- Prisma ORM

### Deployment
- Docker
- AWS EC2
